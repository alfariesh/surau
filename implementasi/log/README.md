# Arsip log sesi

Folder ini berisi jurnal sesi bulan-bulan sebelumnya, satu berkas per bulan: `YYYY-MM.md`. Isinya dipindah apa adanya dari [`../LOG.md`](../LOG.md), tanpa diubah.

Per 2026-10-28 belum ada arsip LOG, karena semua entri masih Oktober 2026 dan tetap di `LOG.md`. Awal bulan berikutnya, entri bulan lalu dipindah ke sini.

Folder ini juga memuat arsip teks lama `STATUS.md` dengan nama `STATUS-arsip-YYYY-MM.md` (lihat [ADR-120](../keputusan/ADR-120.md)). Arsip itu tidak diatur oleh aturan di atas.
