## ADR-140 · Patch keamanan Next 16.4.6 + OpenNext 1.20.17 (tanpa lompat minor) — diterima · 2026-11-26

**Konteks:** `next dev`/`next build` Next 16.4.2 berhenti sekali dengan pesan "Your version of Next.js is affected by a known security vulnerability" (sesi X31a). Endpoint advisori npm (`/-/npm/v1/security/advisories/bulk`) untuk `next@16.4.2` mengembalikan 7 advisori, semuanya **moderate** dan semuanya ditambal di **16.4.5** (rentang rentan berakhir di `<=16.4.4`):

| GHSA | Judul ringkas | Mengenai Surau? |
|---|---|---|
| GHSA-mfr8-8qww-v76h | kebocoran root param, `'use cache'` lewat `unstable_cache` | tidak: tanpa `'use cache'`/`unstable_cache` (ADR-003) |
| GHSA-vc7v-qv4w-wrv8 | kebocoran cache antar root param pada `'use cache'` bersarang | tidak: idem |
| GHSA-vvgp-ww4w-46vf | poisoning fallback shell Cache Components | tidak: `cacheComponents` mati |
| GHSA-rhh4-g77r-r9qj | kebocoran/poisoning `use cache` dengan argumen biner | tidak: idem |
| GHSA-7qx7-33qx-rqx2 | SVG lolos filter optimasi gambar | tidak: `images.unoptimized: true` |
| GHSA-f3mh-rxg3-f5g2 | cookie HttpOnly bocor lewat header internal, runtime Edge | tidak langsung: tanpa `runtime = 'edge'` |
| GHSA-pc58-hwjq-p385 | injeksi/pengungkapan respons antar klien pada self-hosted yang meneruskan respons fetch | mungkin: Surau self-hosted (OpenNext) |

Pilihan versi (dicek 2026-11-26 ±09:00 UTC): Next 16.4.3 dan 16.4.4 masih rentan; **16.4.5** (3 Nov) rilis keamanan; **16.4.6** (9 Nov) = `latest`, tanpa advisori. OpenNext `@opennextjs/cloudflare` sejak 1.20.16 memakai peer `next >=15.5.29 <16 || >=16.4.5`. 1.20.18 punya regresi (500 untuk request ber-`Cookie` bila ada `proxy.ts`/`middleware.ts` runtime Node; Surau tidak punya, tetapi tidak perlu diambil); 1.20.19 memperbaikinya tetapi berumur ±16 jam, jadi ditolak `minimumReleaseAge`.

**Keputusan:**
1. Catalog: `next` **16.4.6**, `@opennextjs/cloudflare` **1.20.17** (`@opennextjs/aws` transitif 4.1.12 → **4.1.16**, yang juga menutup beberapa kebocoran header internal Next). Tetap di minor 16.4; **tanpa** lompat ke 16.5.
2. `next upgrade --agent=security` yang disarankan pesan alat **tidak** dipakai: perubahan hanya kenaikan versi di catalog, tanpa codemod, tanpa perubahan kode aplikasi. Tidak ada `eslint-config-next`/`@next/*` di repo.
3. `minimumReleaseAge` tidak disentuh; 1.20.19 diambil lewat Dependabot/sesi berikutnya bila sudah berumur.
4. Larangan ADR-003/ADR-030 dipertahankan tanpa perubahan; advisori ini justru menegaskan nilainya (6 dari 7 hanya mengenai fitur yang dilarang).

**Ditolak:** Next 16.5 (canary; OpenNext belum mendukung, X01/STATUS menahannya); OpenNext 1.20.18 (regresi cookie); 1.20.19 lewat `minimumReleaseAgeExclude`; tetap di OpenNext 1.20.13 (peer-nya `>=16.4.1` menerima 16.4.6, tetapi OpenNext sendiri menaikkan batas bawah ke 16.4.5 dan 1.20.14–1.20.17 membawa perbaikan request konkuren Next 16 dan kebocoran header).
**Konsekuensi:** `pnpm audit --prod` tidak lagi memuat advisori `next`. Efek samping lockfile: `@node-minify/*` 9 → 10.5 (transitif `@opennextjs/aws`), sehingga `glob@10.3.3` (GHSA-5j98, mitigasi ADR-003) hilang dari pohon dependensi; `terser` 5.36 → 5.46 (satu salinan, peer opsional vite-plus/vitest ikut berganti kunci, versinya tetap). Rujukan rilis: https://github.com/opennextjs/opennextjs-cloudflare/releases (1.20.14–1.20.19) dan https://github.com/vercel/next.js/releases/tag/v16.4.5. Advisori lain yang masih terbuka (bukan bagian ADR ini): `hono` <4.13.16 di `apps/api` (4 moderate + 1 low) dan `figlet` <1.11.3 (high, transitif lewat `@heroui-pro/react` → `heroui-pro`, hanya CLI).
**Tinjau ulang bila:** advisori baru mengenai 16.4.6, OpenNext merilis dukungan 16.5, atau 1.20.19+ sudah berumur >24 jam (naikkan sebagai patch biasa).
