## ADR-151 · Situs dibuka lagi dengan Gelombang 1: tampil tiga kitab, hub Intisari Bab, Ihya 404 — diterima · 2026-11-27

**Konteks:** pembaca, Cari, dan MCP produksi ditutup sejak Ihya diarsipkan (ADR-142). Konten Bidayat al-Hidayah, at-Tibyan, dan al-Ajurrumiyyah sudah lengkap di staging, kecuali audio (PR #260). X31b langkah 6–7 meminta langkah tampil dan satu PR promote yang membuka situs lagi. Pemilik meminta disiapkan di chat 2026-11-27 ("Yes, prepare it").

**Keputusan:**
1. **Satu PR membuka semuanya.** Isinya: `READER_ENABLED` web dan `KITAB_OPEN` MCP menjadi "1", ledger ketiga kitab `tayang`, binding `CORPUS_DB` + `SEARCH_CACHE_CORPUS` ke `surau-corpus-kitab-v10` (ditulis oleh `corpus:promote kitab-v10 --confirm`), landing, `/lisensi`, dan cek produksi di `deploy.yml`. Merge PR ini = situs terbuka. Rollback = revert PR ini (binding dan sakelar sekaligus), bukan `--switch-only` saja.
2. **`/lisensi`** hanya mencantumkan kitab yang tayang. Ihya dihapus dari `EDITION_CREDITS`; atribusinya tetap di `data/ATTRIBUTION.md` dengan tanda diarsipkan.
3. **URL lama `/kitab/ihya/…` → 404** (karya tidak ada di korpus). Tanpa halaman "diarsipkan" dan tanpa 410: tidak ada kode baru, mesin pencari membuang URL-nya, dan bila Ihya kembali URL yang sama hidup lagi (permalink ADR-029 tetap). `deploy.yml` menguji `/kitab/ihya/1/200` = 404.
4. **Suara minat berhenti** untuk tiga slug yang tayang (`RELEASED_SLUGS`). Entrinya tetap di daftar kandidat supaya hitungan lama masih terbaca di `/admin`.
5. **Hub Intisari kitab kecil:** karya tanpa Intisari Kitab menampilkan daftar Intisari Bab menurut urutan daftar isi dalam satu kelompok tanpa judul (ADR-147 butir 3). Tombol Intisari di halaman karya tampil bila karya punya Intisari apa pun.

**Akibat:** promote ke D1 produksi butuh izin pemilik, dan classifier mode otomatis menolak perintah promote (juga mode rencana). Karena itu pemilik menjalankan `pnpm run corpus:promote kitab-v10 --confirm` sendiri di Terminal, lalu agent meng-commit binding hasilnya, menjalankan `corpus:qa kitab-v10`, mencatat `data/SOURCES.md`, dan menggabungkan PR sesudah CI hijau.

**Ditolak:** membuka sakelar sebelum binding diganti (situs akan memuat korpus `ihya-v9`, yang berisi Ihya); halaman "diarsipkan" khusus Ihya (kode baru untuk satu karya yang tidak tayang).
