## ADR-123 · Uji model jawaban Maknaz: Sonnet 5.5 menaikkan kesetiaan dan atribusi, tetapi ±17× lebih mahal; produksi tetap Haiku 5.5 sampai pemilik memutuskan — sementara · 2026-10-28

**Konteks:** empat run berbayar dengan Haiku 5.5 (x07–x10, `answer@7`/`@8`) tertahan di kesetiaan 71–86% (syarat R4 ≥ 95%) dan bahasa 3,26–3,55 (≥ 4); iterasi prompt tidak lagi menaikkan angka. Model jawaban adalah tuas besar yang belum diuji. Ada jalur Sonnet 5.5 di produksi, tetapi hanya sebagai ulangan bila Haiku ditolak (ADR-064/065).

**Keputusan:**
1. **Opsi eval `eval:jawab answer --model sonnet`** (hanya eval, produksi tidak berubah): `JawabDeps.answerModel` membuat tahap jawaban memakai Sonnet 5.5 langsung, tanpa ulangan ke model lain; routing tetap Haiku. Worker `surau-api` tidak pernah mengisinya. Pagu run Sonnet boleh sampai US$6 (Haiku tetap ≤ US$3), biaya terburuk per soal dihitung dengan tarif Sonnet, dan arsip diberi akhiran `+jawab-sonnet` di `prompt_version`.
2. **Perintah gratis `eval:jawab arsip-sebagian`** menyusun arsip, skor kode, dan laporan dari `<run>-sebagian.jsonl` bila tahap penilaian-kode gagal sesudah semua jawaban tersimpan (koneksi D1 remote putus di run ini). Berkas sebagian kini juga menyimpan `usage`, `diagnostics`, dan `blocks`.
3. **Satu run publik 42 soal berbayar** (`x22-publik-sonnet-v1`, izin pemilik di chat 2026-10-28, pagu US$4, terpakai **US$2,0761**) dengan rute x10 dipakai ulang (`--rute`), sehingga dokumen sama dan selisih hanya dari model.
4. **Penilaian buta dan acak:** 84 jawaban (42 Sonnet + 42 x10 Haiku, dinilai ulang) diacak dan dinilai enam subagen agent tanpa nama model, atas teks Arab D1 `ihya-v9` (pengganti sementara, ADR-105; bukan penilaian ustadz).
5. **Hasil** ([laporan](../../evals/reports/jawab-x22-sonnet-banding.md)): kesetiaan 64,3% → **92,9%**, atribusi 83,3% → **100%**, bahasa 3,55 → **3,76**, Benar/Kurang/Salah 31/7/4 → **36/5/1**; lokasi (kode) 85,3% → 85,3%, status hadits 5/6 → 5/6, kutipan valid 100%, fatwa 0. Berpasangan: kesetiaan lebih baik di 14 soal, lebih buruk di 2 (p ≈ 0,004). Belum satu pun syarat R4 yang terpenuhi, dan syarat lokasi dan sebagian bahasa bukan urusan model.
6. **Biaya:** Sonnet US$0,049 per jawaban (+ routing ±US$0,001) vs Haiku US$0,0029 (±17×). Di US$20 per bulan itu ±400 soal (Haiku ±6.900); menampung 6.900 soal per bulan butuh ±US$345. Reservasi ledger per pertanyaan akan naik dari ±US$0,016 ke ±US$0,25 bila Sonnet menjadi model utama.
7. **Produksi tetap Haiku 5.5 dengan ulangan Sonnet.** Mengganti model utama, menaikkan anggaran P-4, atau menurunkan kuota adalah keputusan pemilik; Jawab produksi tetap mati sampai `/rilis 4`.

**Ditolak / belum diuji:**
- Mengganti model produksi sekarang: biaya ±17× tidak muat di P-4, dan R4 tetap belum terpenuhi.
- Hibrida (Sonnet hanya untuk status hadits atau hasil "tidak ditemukan", atau sebagai ulangan bila verifikasi Haiku gagal), serta effort Sonnet yang berbeda: perlu run berbayar baru dengan izin.
- Memperlakukan angka ini sebagai estimasi resmi: penilainya agent, satu run per model.

**Konsekuensi dan batas:** derau penilai besar. Jawaban x10 yang sama dinilai 23 Benar / kesetiaan 78,6% / bahasa 3,26 di laporan x10, tetapi 31 / 64,3% / 3,55 di penilaian buta ini (rubrik ditulis ulang karena teks prompt penilai lama tidak tersimpan; definisi kesetiaan di sini lebih ketat). Angka mutlak tidak sebanding dengan x07–x10; hanya perbandingan Haiku vs Sonnet dalam penilaian yang sama yang sah. `pipeline@13` (Haiku) vs `@15` (Sonnet) hanya berbeda di j025 dan j026. Rute x10 dipakai ulang, jadi routing tidak diukur.

**Tinjau ulang bila:** pemilik memutuskan anggaran dan kuota Jawab, penilai manusia (Anas) menilai pasangan ini, harga Sonnet atau Haiku berubah, atau retrieval lokasi diperbaiki sehingga selisih model bisa diukur ulang.
