## ADR-152 · Gelombang 2: kitab dari daftar CSV pemilik, korpus `kitab-v11`, pengisian penanda halaman OpenITI tanpa nomor, node akar lewat patch — diterima · 2026-11-28

**Konteks:** Gelombang 1 (X31, ADR-142, ADR-151) tayang dengan tiga kitab kecil. Pemilik meminta (chat 2026-11-28, `/goal`): "proses kitab dari shet tadi sampai max cost 90 usd. Pakai batch API … Pakai sonnet batch api untuk ingest, dan skip audio dulu", lalu "anda bebas melakukan command apapun. saya izinkan semuanya". "Shet tadi" = tiga CSV pencocokan katalog di drive Shamela (`classics_db_match_report.csv`, `dkislamiyah_db_match_report.csv`, `hasil_pencarian_kitab.csv`; docs/03-sumber-data.md).

**Keputusan:**
1. **Urutan pilihan kitab:** kitab berstatus SAME di CSV yang sudah ada di "Segera hadir" (ADR-115), klasik (penulis wafat sebelum abad ke-14 H, kecuali disebut), punya versi OpenITI ber-ID Shamela sama, nomor halaman Shamela sesuai cetakan (bukan "مرقم آليا"), dan kecil lebih dulu. Gelombang 2 dimulai dengan **al-Munqidz min adh-Dhalal** (Shamela 9246, karya 5, edisi 5) dan **al-Waraqat** (Shamela 6297, karya 6, edisi 6, pengarang 4). Kitab berikutnya ditambahkan dengan aturan yang sama dan dicatat di tabel "Catatan hasil" sesi X32.
2. **Korpus bawaan menjadi `kitab-v11`** berisi Gelombang 1 + 2. ID kitab Gelombang 1 tidak berubah (sidik teks ADR-059). Status ledger kitab baru `staging` sampai lolos "Definisi selesai" X31 (cetakan yang sama), lalu `tayang`.
3. **Penanda halaman OpenITI tanpa nomor** (`PageV00P000`, 17 dari 26 penanda di berkas al-Waraqat): opsi per kitab `openiti.fillZeroPageMarkers` mengisi nomornya dari urutan. Setiap deret tanpa nomor di antara dua penanda bernomor wajib pas mengisi celahnya; bila tidak, ingest gagal. QA matan per halaman (≥ 0,95) tetap berlaku sesudah pengisian, sehingga pemasangan yang salah tetap tertangkap. al-Waraqat: 25/25 halaman lolos.
4. **Patch daftar isi boleh menambah node tingkat teratas** (`parent: 0`). Dipakai al-Waraqat: paragraf basmalah sebelum judul pertama menjadi node sendiri (judulnya disalin dari halaman), sama dengan judul pertama al-Munqidz di Shamela.
5. **al-Munqidz `matanMinPages` 92 dari 93:** halaman cetak 128 berkemiripan 0,897 karena empat judul Shamela berada di tengah kalimat dan di OpenITI menjadi baris judul tersendiri; 93% token berurutan, teksnya sama. Pengecualian ini tidak melonggarkan ambang per halaman.
6. **Edisi Gelombang 2 memakai Intisari Bab saja** (`SECTION_ONLY_EDITIONS` + 5, 6), seperti ADR-147.
7. **Biaya:** batch Sonnet 5.5 (Message Batches API) tanpa konfirmasi per batch, total ≤ US$90 untuk seluruh pekerjaan ini; biaya nyata dicatat di LOG. Audio tidak dibuat.
8. **Lisensi:** pin commit `master` repo OpenITI saat diunduh (2026-11-28), dicatat di `data/SOURCES.md`, dengan label rilis 2025.1.9 seperti Gelombang 1. Bila berkas ternyata tidak ada di rilis Zenodo 2025.1.9, atribusi diganti ke commit GitHub (tinjau ulang).

**Menyimpang dari rencana:** X31 "Di luar cakupan" menyebut al-Munqidz dan kitab lain. Pemilik kini memintanya; dicatat sebagai sesi baru X32.

**Tinjau ulang bila:** OpenITI memperbaiki penanda halaman al-Waraqat (opsi pengisian dimatikan), atau anggaran/pilihan kitab diubah pemilik.

### Tambahan: al-Muqaddimah al-Hadhramiyyah

Kitab ketiga Gelombang 2 (2026-11-28): **al-Muqaddimah al-Hadhramiyyah (Masa'il at-Ta'lim)**, Bafadl al-Hadrami (w. 918 H), Shamela 6125, karya 7, edisi 7 (`ad-dar-al-muttahidah`), pengarang baru 5 (Shamela author 1677). Edisi: tahqiq Majid al-Hamawi, ad-Dar al-Muttahidah, Damaskus, cetakan ke-2 1413 H; 142 halaman, nomor halaman sesuai cetakan (19–162). OpenITI `OpenITI/0925AH` dipin ke commit `master` `4f0f4562d1e13083c593e3a0ca6a19a3eb33805e`.

1. **Catatan kaki `none`:** 142 halaman tanpa garis pemisah catatan kaki. Badan edisi juga tanpa mukadimah pentahqiq (page.id 1 = mukadimah penulis), jadi tidak perlu patch teks pentahqiq seperti ADR-150.
2. **Daftar isi bertingkat lewat patch** (`data/patches/al-muqaddimah-al-hadhramiyyah-6125.yaml`). Shamela hanya menandai 99 judul, semuanya di akar ("fasl", plus satu "bab" = title 20). Judul "kitab" ada sebagai teks sebaris di awal paragraf (`=كتاب … = …`) dan judul "bab" diapit artefak konversi `- صلى الله عليه وسلم - باب … - صلى الله عليه وسلم -` (sama persis di OpenITI, jadi teks tidak diubah). Hasilnya 118 node: 6 di akar (mukadimah, Thaharah, bab Shalat, Zakat, Shiyam, Hajj), 62 di tingkat 2, 50 di tingkat 3. "باب الصلاة" ditaruh di akar karena berfungsi sebagai kitab shalat (tidak ada "كتاب الصلاة" di sumber); bab shalat lain menjadi anaknya. Fasl mengikuti kitab/bab terakhir sebelumnya menurut urutan teks. Jumlah node akar memang 6, bukan 10–20: kitab ini hanya punya empat "kitab".
3. **Perubahan kecil pencocok judul patch** (`toc.ts`, `patch.ts`): (a) paragraf dianggap "dibuka" kata judul bila sebelum kecocokan hanya ada tanda baca/spasi (sebelumnya wajib offset mentah 0, sehingga `=كتاب` gagal); (b) field opsional `prefix` untuk kata yang mendahului judul tetapi bukan bagian judul (artefak di atas); judul node disalin dari `heading` saja. Kata judul di tengah kalimat tetap ditolak (tes `toc.test.ts`).
4. **Gerbang:** semua lolos, termasuk matan = OpenITI 142/142 halaman (≥ 0,95), tanpa pengecualian `matanMinPages`. Penanda `PageV00P000` hanya satu di awal berkas, jadi `fillZeroPageMarkers` tidak dipakai. Smoke: halaman cetak 50, kata pencarian "التيمم".
5. **Intisari Bab:** edisi 7 masuk `SECTION_ONLY_EDITIONS`. `intisari_bab` di ledger belum diisi karena keenam node akar adalah node patch (bukan `title.id` Shamela); ID-nya dicatat sebagai komentar ledger.
6. **Biaya rencana putaran 1** (`pnpm llm plan`, count_tokens saja, belum dikirim): 617 request, TOTAL cache 95% US$2,33 / cache 50% US$5,38 / cache 0% US$8,76.
7. **Fixture tes:** `packages/db/test/fixture.ts` memakai edisi buatan 7 sebagai kitab bertingkat dengan Intisari Kitab; karena 7 kini edisi nyata section-only, fixture dipindah ke edisi 90 (di luar ID kitab nyata). Tidak ada ID produksi yang berubah.
