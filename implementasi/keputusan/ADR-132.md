## ADR-132 · Terjemahan Inggris per paragraf lewat plugin `surau-redaksi` (langganan, Sonnet), bukan batch API: format `surau-terjemah/1`, aturan batch yang sama, periksa independen per berkas — diterima · 2026-10-28

**Konteks:** ADR-130 menetapkan bahasa Inggris sebagai satu-satunya bahasa bantuan baca di MCP. Rencana X26 membuatnya lewat batch API (±US$35–45 dengan Sonnet). Pemilik (2026-10-28): "API saya mulai menipis, belum untuk eval AI juga. Jadi sementara pakai plugin, dan untuk terjemah pakai Sonnet."

Sebelum pemilik memutuskan, agen sudah menyampaikan risikonya:
- **Waktu:** ±16.000 paragraf, kira-kira 400 percakapan.
- **Kuota:** kuota langganan dipakai bersama sesi agen lain.
- **Mutu:** keseragaman mutu lebih sulit dijaga daripada batch berprompt tetap.
- **Pemakaian:** pemrosesan massal tidak sesuai dengan maksud langganan untuk kerja interaktif.

**Keputusan:**
1. **Terjemahan Inggris dibuat di chat** dengan skill `terjemah-inggris` (plugin 0.2.0), model **Sonnet**, satu berkas ≤ 40 paragraf per percakapan.
   - Pembuatnya pemilik di Claude Desktop atau agen di Claude Code; keduanya memakai langganan.
   - Aturan terjemahannya (`references/aturan.md`) adalah `translate-passage@5` (ADR-109) yang dialihkan ke bahasa Inggris, ditambah glosarium Inggris.
2. **Bahan dan pemeriksa sama dengan batch** (endpoint `/redaksi`, X23):
   - `list_translation_units` memberi teks Arab dengan ayat sudah diganti placeholder (`maskAyat`). Paragraf yang rujukan ayatnya tidak bisa ditandai diblokir, persis aturan `translationUnits` batch.
   - `check_translation_draft` menjalankan `checkPassageTranslation(…, "en")`. Pemeriksa batch dipindah dari `@surau/llm` ke `@surau/core` tanpa mengubah perilakunya untuk bahasa Indonesia; tes lama lolos.
   - Rasio panjang Inggris (0,65–3,5) belum dikalibrasi, jadi hanya peringatan.
3. **Format `surau-terjemah/1`**, disimpan di git di `data/terjemah/en/<section_id>-<passage_id pertama>.json`.
   - Isinya hanya ID paragraf dan teks Inggris (dengan placeholder dan penanda), tanpa teks Arab.
   - Kolom `asal` (model, plugin, skill, operator) dan `periksa` (mandiri, independen, kode) sama dengan `surau-konten/1`.
4. **Gerbang `siap`** memakai pola tiga lapis ADR-125:
   - cap kode `terjemah@1` yang cocok dengan isi;
   - periksa mandiri tanpa Salah;
   - periksa independen oleh agen konteks segar (`pemeriksa-konten`) atas sampel butir. Sampelnya minimal 5 butir atau 20% butir, dipilih pemeriksa, dan selalu mencakup paragraf berplaceholder ayat. Satu Salah = berkas diperbaiki dan diperiksa ulang.

   Penilaian itu penilaian AI, bukan manusia (ADR-105). Label publiknya tetap "AI translation".
5. **CLI `pnpm terjemah cek|impor|daftar`** (korpus remote hanya-SELECT, sama dengan `pnpm konten`). `daftar` menghitung paragraf `siap`.
6. **Urutan kerja:** bagian yang dipakai Intisari v2 dan Jalur lebih dulu (Kitab al-'Ilm), lalu Kitab lain di Rub' pertama. Bahan dibaca per Kitab ke bawah: bagian yang melewati 6.000 baris (satu Rub') ditolak (`section_too_large`), bukan dipotong. Sidik sumber dicek ulang oleh `pnpm terjemah cek` (`source_stale`); sidik per paragraf untuk loader menyusul di X26.

   MCP tetap berbahasa Indonesia sampai cakupan Inggris lengkap dan peralihan X26 dikerjakan. Pemuatan ke korpus (tabel `translation`, `lang = 'en'`, `model` = model di `asal`, `prompt_version` = `surau-redaksi/terjemah-inggris@1`) juga dikerjakan di X26.

**Menyimpang dari rencana:**
- X26 langkah 1–3 (batch API, pilot berbayar, eval berbayar) diganti produksi lewat plugin dan eval agen berlangganan.
- Biaya API terjemahan menjadi US$0, sedangkan biaya waktu dan kuotanya besar.
- Perbandingan mutu dengan terjemahan Indonesia memakai penilai agen pada sampel yang sama, bukan eval berbayar.

**Tidak dipilih:**
- *Batch API Sonnet* (saran agen): saldo API pemilik menipis.
- *Batch API Haiku* (±US$3–5): mutunya jauh di bawah Sonnet pada uji X21.
- *Menerjemahkan dari terjemahan Indonesia:* terjemahannya bertingkat, dan kesalahan versi Indonesia ikut terbawa.

**Tinjau ulang bila:**
- saldo API kembali cukup: sisa paragraf lebih murah dan seragam lewat batch dengan aturan yang sama, karena pemeriksanya sudah satu;
- penilai agen menemukan Salah > 3% pada sampel;
- kuota langganan menghambat sesi pengembangan.
