## ADR-125 · Konten turunan lewat Claude Desktop + plugin `surau-redaksi`: format `surau-konten/1`, cek otomatis tiga lapis, endpoint MCP `/redaksi` — diterima · 2026-10-28

**Konteks:** pemilik meminta jenis konten di luar korpus (teks Arab, terjemahan, takhrij) difinalkan, dengan standar, pedoman, dan alat produksi yang murah. Riset [2026-10-27](../../docs/riset/2026-10-27-ringkasan-buku-dan-pecahan-produk/README.md) menyimpulkan isi dan jangkar Intisari kuat tetapi pembungkusnya lemah (2,65/5), dua gagasan bernilai Salah masih tayang, dan perbaikan isi ("Tahap B": inti satu kalimat, judul bervariasi, soal berjawaban) menunggu izin batch API berbayar. STATUS mencatat X15c (batch penuh Intisari, berbayar) sebagai langkah berikutnya. Pemilik memilih produksi lewat Claude Desktop dengan plugin (langganan, tanpa biaya API) untuk sementara; fase manusia/ustadz menyusul sebagai fase sendiri. Fakta yang ditemukan: klien claude.ai memotong instruksi server MCP di ±2.048 karakter; data kerja Intisari batch tidak ada di Mac pemilik (ada di mesin agen); plugin Claude bisa dipasang dari marketplace GitHub (repo publik) di Chat, Desktop, dan Cowork, dengan skill sebagai komponen utama dan konektor MCP jarak jauh yang disambungkan pengguna sendiri.

**Keputusan:**
1. **Katalog jenis v1:** Intisari Bab (standar v2), Intisari Kitab, Faedah, dan Jalur 7 hari. Rangka (lapisan korpus, konten turunan, kemasan) dan standar per jenis ada di [docs/09-konten.md](../../docs/09-konten.md); pedoman produksi di [docs/redaksi-operasional.md](../../docs/redaksi-operasional.md). Istilah, Dengar, dan Rujukan tetap dibuat kode/pipeline lama; Bahan Kajian ditunda.
2. **Produksi lewat Claude Desktop + plugin `surau-redaksi`** (`plugins/surau-redaksi/`, marketplace di `.claude-plugin/marketplace.json` root repo), bukan batch API. Batch API dan audio tetap butuh izin pemilik (aturan keras 4). X15c tidak dijalankan untuk bagian yang punya draf dari chat.
3. **Format berkas `surau-konten/1`** (skema `contentDraft` di `@surau/core`), satu berkas per unit di `data/konten/<jenis>/` (masuk git). Isinya hanya teks Indonesia, ID, dan offset. Kutipan = `passage_id` + `char_start`/`char_end` dari `verify_quote`; kode menyalin teks Arab saat build dan baca (teks-arab.md aturan 1). Terjemahan Faedah tidak ada di berkas; kode menyalinnya.
4. **Gerbang terbit (keputusan pemilik 2026-10-28): cukup cek otomatis, tiga lapis.** (a) Cek kode `checkContentDraft` (skema, lint narasi, cek korpus) yang sama di MCP `/redaksi`, CLI `pnpm konten`, dan build X23. (b) Periksa mandiri AI di chat dengan daftar uji (negasi, bilangan dan waktu, sikap tiga arah, ta'wil, aliran, fatwa). (c) Periksa independen oleh agen konteks segar di Claude Code saat impor (`.claude/agents/pemeriksa-konten.md`), skala Benar/Kurang/Salah X15; satu Salah = tidak terbit. Label "Intisari AI, belum ditinjau manusia" tetap; penilaian agent tidak pernah dilabeli manusia (ADR-105). Ini **menyimpang** dari saran riset (Faedah dan Jalur dicek manusia dulu). Mitigasi: daftar putih Faedah ketat (tanpa ayat, tanpa penanda hadits, tanpa `needs_review`, bukan pendapat yang dinukil/dibantah), Jalur hanya ke bagian ber-Intisari, `status: "ditarik"` untuk tarik cepat, tombol Laporkan di X23.
5. **Endpoint MCP `/redaksi`** di Worker `surau-mcp` yang sama: 8 tool baca + `check_content_draft` + `list_faedah_candidates`, instruksi sendiri ≤ 2.000 karakter. `/mcp` publik tetap 8 tool dan kontraknya tidak berubah (docs/05 §11). Tanpa LLM dan tanpa login. Kunci batas per klien diberi lingkup endpoint (ember sendiri, tidak berbagi dengan pengguna claude.ai lain di `/mcp`), sedangkan plafon global baca dan FTS tetap satu untuk kedua endpoint; dua tool redaksi memakai limiter sendiri `MCP_REDAKSI_LIMITER` (30/menit per klien dan 30/menit semua klien); telemetri `mcp_tool`/`mcp_error` diberi label `endpoint`. Draf tidak pernah digemakan di hasil atau log.
6. **Satu aturan untuk semua tempat:** pemeriksa narasi, `quoteInspector`, `digestTierOf`, dan daftar takhrij terlarang (`QUOTE_BANNED_TAKHRIJ_KINDS`) dipindah ke `@surau/core` dan diekspor ulang di tempat lama (pola ADR-081); batas kata kutipan lewat `isQuoteSpan` di `@surau/text` (aturan 3).
7. **Standar judul (docs/05 §12):** setiap judul gagasan menyebut pemilik pendapat; paling banyak sepertiga judul dibuka "Al-Ghazali" (atribusi boleh di anak kalimat, opsi A riset 08); inti satu kalimat dan tidak dibuka "Bagian ini membahas"; setiap soal punya jawaban satu kalimat.
8. **Tingkat tinjau** dinamai R0 (otomatis) sampai R3 (ustadz), bukan T0–T3, supaya tidak tertukar dengan nomor tugas pemilik T-NN.

**Ditolak:**
- Batch API untuk Tahap B dan X15c sekarang: butuh izin biaya; pemilik memilih chat.
- Menambah tool redaksi ke `/mcp` publik: memperbesar konteks setiap pengguna dan mengubah kontrak §11.
- Mengubah draf menjadi rekaman `acceptedDigest` batch: pemeriksa kesegaran batch (`prompt_version`, sidik blok) akan membuangnya; X23 membangun baris DB langsung dari draf.
- Model menyalin teks Arab ke dalam draf: urutan harakat bisa tertukar; cukup angka offset.
- Cowork menulis langsung ke repo sebagai jalur utama: tugas Pro/Max kini berjalan di cloud dan perilaku tulis-balik ke folder lokal belum terdokumentasi; jalur utama adalah unduh berkas lalu impor oleh agen.
- Token rahasia di URL `/redaksi`: repo publik.

**Konsekuensi:**
- Kuota langganan dipakai bersama oleh produksi konten di Chat dan sesi agen Claude Code.
- Penulis dan pemeriksa independen satu keluarga model; kesalahan bisa berkorelasi (kasus *sanah*/*sunnah* bisa lolos dua-duanya). Pedoman menganjurkan model berbeda untuk pemeriksa.
- Aturan WAF T-19 hanya melindungi `/mcp`; `/redaksi` hanya dilindungi limiter Worker sampai aturan WAF diperluas (konfigurasi di luar repo, tugas pemilik T-34).
- X23 (impor dan tampil): skema korpus 10 (`digest.lead`, `digest_question.answer`), Intisari induk (100004, 100003) ikut basi saat anaknya diganti, dan audio enam bab gugur bila naskahnya berubah (rekam ulang berbayar, izin pemilik).
- Plugin berlisensi Apache-2.0; contoh di `references/` yang diturunkan dari Ihya berlisensi CC BY-NC-SA 4.0 dengan atribusi.

**Tinjau ulang bila:** ada peninjau manusia kedua yang aktif (naikkan gerbang Faedah/Jalur ke R1), laporan kekeliruan atas konten chat melebihi 2% gagasan, atau perilaku plugin/konektor claude.ai berubah.
