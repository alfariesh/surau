## ADR-118 · Evaluasi vinext dan TanStack Redact: tetap Next 16 + OpenNext, ditinjau ulang bila pemicunya terpenuhi — diganti oleh ADR-119 · 2026-10-27

> **Diganti oleh ADR-119 (2026-10-28):** angka hidrasi dan e2e di bawah diukur lewat HTTP/1.1 tanpa kompresi. Diulang lewat proksi HTTP/2 + brotli dan Lighthouse ponsel, LCP halaman kitab vinext 42–52% lebih cepat, sedangkan hidrasi +1,1 dtk. Keputusan "tetap Next tanpa uji lanjut" diganti menjadi gerbang Preview.

**Konteks:** ADR-003 menolak vinext (waktu itu beta, 2 advisory) sebagai cadangan dan meminta evaluasi ulang. Pemilik meminta penilaian sebelum peluncuran, saat ganti stack masih murah. Sejak itu vinext sudah 1.3.1 (25 Okt, [Cloudflare](https://github.com/cloudflare/vinext)) dan TanStack Redact 0.2.x terbit (26 Okt, [artikel](https://tanstack.com/blog/introducing-tanstack-redact)). Dinilai lewat uji coba nyata, bukan dari brosur: cabang `spike/vinext` (vinext 1.3.1 + `@cloudflare/vite-plugin` 1.65 + wrangler 4.152.0, jalur `--legacy-wrangler-cloudflare-init`), dijalankan di workerd dengan D1 lokal, dibandingkan dengan `main` apa adanya (Next 16.4.2 + OpenNext 1.20.12) pada data lokal yang sama.

**Hasil uji coba (diukur 2026-10-27):**
- **Migrasi murah dan bisa dibalik.** `vinext check` tidak menemukan masalah di kode sumber (82% itu menghitung berkas hasil build `.open-next/`); yang parsial hanya `ViewTransition` (2 berkas, tidak beranimasi). Perubahannya 5 berkas: `wrangler.jsonc` (entri baru, buang binding R2 cache + self-reference OpenNext), `worker/index.ts` (baru), `vite.config.ts` (baru), `src/lib/cloudflare.ts` (`getCloudflareContext` → `cloudflare:workers`; satu-satunya berkas Surau yang menyentuh API OpenNext), dan `next.config.ts` (buang `initOpenNextCloudflareForDev`). Butuh wrangler ≥ 4.152.0 (peer plugin). Build lolos pertama kali; 12 rute kunci HTTP 200 dengan D1 asli.
- **Build:** 8,4 dtk vs 13,8 dtk (`next build` + bundel OpenNext). **JS klien seluruh chunk (gzip):** 603 KB (181 berkas) vs 798 KB (77 berkas), −24%. Keunggulan "2× lebih cepat" di brosur tidak berarti di aplikasi sekecil ini.
- **Hidrasi lebih lambat.** Halaman yang sama memuat 118 permintaan skrip (116 `modulepreload`, `type="module"`) vs 31 (`<script async>`). Hidrasi React selesai 97–163 ms **sesudah** event `load` (Next: 11–26 ms), diukur di localhost tanpa latensi jaringan; di ponsel dengan jaringan nyata belum diukur dan bisa lebih buruk. Akibatnya 44 tes e2e (22 tes × chromium dan chromium-ponsel) gagal karena mengklik sebelum halaman menyala: baseline 15 gagal (semuanya karena D1 lokal bernormalisasi lama: kueri Arab), vinext 59. Yang mungkin mengurangi jumlah chunk (`build.rolldownOptions.output`) tidak dicoba.
- **Cache halaman belum terjawab.** Tanpa adapter cache, halaman ISR kitab dilayani `Cache-Control: no-store` dan `X-Vinext-Cache: MISS`: setiap kunjungan merender ulang dan membaca D1. Pengganti cache R2 + regional OpenNext (yang sudah terbukti di produksi) harus dipilih dari beberapa mode baru vinext (Response Store, Workers Cache, KV, Static Assets). Cache key vinext punya advisory sendiri (GHSA-2956-r8mj-w5c4, 14 Okt, medium; GHSA-8969-277p-8rrm high menyangkut Server Actions/`"use cache"` yang Surau tidak pakai; keduanya ditambal sejak 1.2.0).
- **Kematangan:** README vinext: "Under active development", pemakaian produksi "You can, with caution", daftar "Used by" kosong, 638 issue dan PR terbuka, rilis minor tiap ±5 hari, hanya menargetkan API Next 16. Jalur Cloudflare default-nya sekarang `cf` CLI + `cloudflare.config.ts`; jalur `wrangler.jsonc` berlabel "legacy". Alur deploy, Preview per PR (`wrangler preview`), dan dokumen operasi Surau semuanya bergantung pada wrangler.
- **Alat agent hilang:** MCP devtools Next (`/_next/mcp`) dan docs Next yang dibundel di `node_modules` (alasan ADR-003 mempertahankan Next) tidak berlaku di vinext.
- **Temuan sampingan, belum diubah:** `READER_SCALE_SCRIPT` (skrip inline root layout) membocorkan `var d, l, s, r, o, m, …` ke scope global; skrip internal vinext (`const o` tingkat atas) bertabrakan dengannya (`Identifier 'o' has already been declared`). Membungkusnya dalam IIFE aman (12 tes `scale.test.ts` lulus) dan layak dilakukan kapan pun sebagai kebersihan, apa pun stack-nya.
- **Redact:** pengganti React DOM sisi browser (SSR/RSC tetap React). 0.2.0 terbit 26 Okt; **0.2.1 baru 10 jam** saat dinilai (ditolak `minimumReleaseAge`). Render sinkron tanpa time slicing; docs sendiri menyatakan **Safari dan Firefox belum diverifikasi** dan paritas animasi belum penuh; tidak ada keterangan soal react-aria/HeroUI/motion. Penghematannya ±36 KB gzip di Next menurut benchmark mereka, sekitar 9% dari ±395 KB JS awal `/tentang` di Surau. Bisa dipasang di Next tanpa vinext, jadi tidak terkait keputusan ini.

**Keputusan:**
1. Tetap Next 16.4 + OpenNext (ADR-003 berlaku). vinext tidak dimigrasi sekarang.
2. Redact tidak dipasang.
3. Jaga agar migrasi tetap murah: kode memakai API Next standar, dan binding Cloudflare hanya diakses lewat `src/lib/cloudflare.ts`. Jangan menambah pemakaian API khusus OpenNext di tempat lain.
4. Hasil uji coba disimpan di cabang `spike/vinext` (satu commit di atas `main` 2026-10-27, tidak untuk digabung). Mengulang uji: `pnpm install`, `pnpm --filter @surau/web build:vinext`, `wrangler dev --config dist/server/wrangler.json --persist-to <root>/.wrangler/state --var IP_HMAC_KEY:uji --var DEV_PAGES:1`, lalu `BASE_URL=… pnpm test:e2e`. Bandingkan selalu dengan `main` pada data D1 yang sama.

**Alasan:** keuntungan bagi Surau kecil (lepas dari OpenNext, dev di workerd asli, bundel lebih kecil) sedangkan kerugiannya terukur (hidrasi lebih lambat, 4× permintaan skrip, cache halaman belum ada jawabannya, matang belum teruji, alat agent hilang). Karena kode Surau hampir murni Next standar, menunda hampir tidak menambah biaya migrasi nanti; Redact belum diverifikasi di Safari, padahal seluruh peramban iOS memakai WebKit.

**Risiko yang diterima:** tetap bergantung pada kecepatan OpenNext mengikuti Next (ADR-003) dan pada penanganan sementara bug ISR-nya (ADR-038).

**Tinjau ulang bila:** (a) OpenNext tertinggal lebih dari satu rilis minor Next atau issue #1250/#1455 menggigit di produksi; (b) vinext punya pengguna produksi publik, panduan cache ISR di Workers yang stabil, dan hidrasi ≤ +30 ms dari baseline pada uji yang sama (coba kurangi chunk lebih dulu); (c) Redact ≥ 1.0, terverifikasi di Safari/Firefox, dan lolos e2e + axe Surau dengan HeroUI/react-aria; uji di Next saat ini, tanpa vinext.
