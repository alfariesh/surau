## Sekarang

- **Mulai di sini (pemilik):** jalankan **T-26** (X08 koreksi terjemahan, ADR-081–082): Anas membuka [surau.org/tinjau/terjemahan](https://surau.org/tinjau/terjemahan) (login sama dengan `/tinjau`), menyalin **kode akun** yang tampil, lalu mengirimnya ke WhatsApp Anda. Anda menulis ke agent "daftarkan kode … sebagai editor terjemahan Ust. Anas Lc.". Setelah itu Anda memantau di [/admin](https://surau.org/admin) → *Koreksi terjemahan terbaru*. Koreksi tampil di situs setelah korpus berikutnya (ketik "bangun korpus dengan koreksi terjemahan"; promote atas izin Anda).
- **Butuh pemilik:** T-26 (di atas) · T-25 (lihat dan setujui tampilan Tanya; ketik "siapkan Preview Tanya") · T-24 (Anas: tinjau label status hadits di [surau.org/tinjau/takhrij](https://surau.org/tinjau/takhrij), isi nama **Anas**; langkah di T-24 butir 5; setelah keputusan pertamanya, ketik ke agent "daftarkan akun Anas sebagai peninjau label") · T-17 tahap 3: diukur ulang agent 2026-10-27 (40 sampel lanjutan, sebelum strata pendek diterjemahkan ulang): Benar 82,1%, Salah 1,1%, "lolos, belum pasti"; sebelumnya 2026-10-26 tidak lolos (ADR-105); penilaian manusia boleh menyusul · T-28 selesai 2026-10-28, tidak lagi butuh pemilik (semula: salin `data/raw/kemenag` dan `data/build/llm` dari Mac; agent memandu saat X15c; tetap jangan hapus `data/build/llm/`) · T-29 (kunci API ElevenLabs terbatas di `.env`, sebaiknya + izin User/Voices Read; kuota produksi ±1,3 juta karakter melebihi Starter) · T-31 butir 4 (penilaian manusia atas QA pilot, boleh kapan saja).
- **Posisi sekarang:** X21 selesai (korpus `ihya-v9` tayang di surau.org, ADR-107/109). Berikutnya **X15c** (Intisari penuh): batch penuh butuh izin biaya. Dua gagasan Salah dari QA pilot X15b (100007 g4, 100017 g2) sudah ditarik dari tampilan produksi lewat daftar tarik di repo, beserta audio kedua bab (ADR-127, 2026-10-28); Intisari v2 keduanya masuk korpus di X23. Sisa header: 5 paragraf tanpa terjemahan dan 62 terjemahan lama yang ditolak validator tiga kali.
- **Gerbang aktif:** `/rilis 4` belum disarankan. Syarat R4 belum terpenuhi: ≥50 soal eval disetujui (48 pada 2026-10-26, ADR-105); lokasi ≥90% (answer@8 run tunggal 91,2%, sebelumnya 85,3%); label status hadits belum ditinjau ustadz (T-24); judge belum terkalibrasi; persetujuan tampilan (T-25) belum ada. Jawab produksi tetap **mati** sampai `/rilis 4`. Uji model jawaban (ADR-123, 2026-10-28): Sonnet 5.5 menaikkan kesetiaan 64,3% → 92,9% dan atribusi 83,3% → 100% (penilai agent buta), tetapi ±17× lebih mahal (±US$0,05 per soal; ±400 soal per US$20); R4 tetap belum terpenuhi, produksi tetap Haiku sampai pemilik memutuskan anggaran/kuota. Mutu Maknaz `answer@8` (ADR-110, run kedua US$0,12): kesetiaan 85,7%, bahasa 3,55, atribusi 92,9%, Salah 2, lokasi 91,2%. Langkah berikutnya kode (bunyi label status, takhrij kemunculan pertama) dan penilaian manusia, bukan prompt lagi.
