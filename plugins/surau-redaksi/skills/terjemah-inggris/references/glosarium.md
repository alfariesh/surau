# Glossary (terjemah@1)

English renderings for Surau's English translation. Transliteration is plain Latin without diacritics ('ayn as ', hamza as ' only where needed), the same spirit as the Indonesian glossary. Write the form on the right; the bracketed transliteration only at its first occurrence in a paragraph.

## Names and formulas
- Allah ta'ala → Allah Most High; Allah subhanahu wa ta'ala → Allah, glorified and exalted is He; 'azza wa jalla → Allah, the Mighty and Majestic
- salla Allahu 'alayhi wa sallam (and short forms) → (peace and blessings be upon him), once after "the Prophet" or "the Messenger of Allah"
- 'alayhi as-salam → (peace be upon him); radiya Allahu 'anhu/'anha/'anhum → (may Allah be pleased with him/her/them); rahimahu Allah → (may Allah have mercy on him)
- Rasul Allah → the Messenger of Allah; an-Nabi → the Prophet
- wa Allahu a'lam → and Allah knows best; in sha' Allah → if Allah wills
- al-Qur'an → the Qur'an; as-sunna → the Sunna

## People and groups
- as-sahaba → the Companions; at-tabi'un → the Followers (tabi'un); as-salaf → the early generations (salaf)
- al-'ulama' → the scholars; al-fuqaha' → the jurists; al-mutakallimun → the theologians (mutakallimun)
- as-sufiyya → the Sufis; al-'arif / al-'arifun → the knower(s) of Allah ('arif); al-murid → the aspirant (murid)
- al-'abid → the worshipper; az-zahid → the renunciant (zahid); as-siddiq → the truthful one (siddiq)
- al-awliya' → the friends of Allah (awliya'); al-muqarrabun → those brought near (muqarrabun)

## Knowledge
- 'ilm → knowledge; 'ilm al-mu'amala → the knowledge of conduct ('ilm al-mu'amala); 'ilm al-mukashafa → the knowledge of unveiling ('ilm al-mukashafa)
- al-fiqh → jurisprudence (fiqh); usul al-fiqh → legal theory (usul al-fiqh); al-kalam → theology (kalam); at-tafsir → Qur'anic exegesis (tafsir)
- al-hadith → hadith; al-athar → report (athar, from a Companion or Follower); al-khabar → report
- al-isnad → chain of transmission (isnad); al-ijma' → consensus (ijma'); al-qiyas → analogy (qiyas); at-taqlid → imitation (taqlid)

## Rulings
- fard 'ayn → individual obligation (fard 'ayn); fard kifaya → communal obligation (fard kifaya); wajib → obligatory
- mustahabb / mandub → recommended; makruh → disliked (makruh); haram → forbidden; halal → lawful; mubah → permissible
- ash-shubuhat → doubtful matters (shubuhat); al-bid'a → innovation (bid'a); al-ma'siya → disobedience; adh-dhanb → sin

## Worship
- at-tahara → purification; al-wudu' → ablution (wudu'); at-tayammum → dry ablution (tayammum); al-ghusl → ritual bath (ghusl)
- as-salat → the prayer; al-jama'a → the congregation; al-jumu'a → the Friday prayer; az-zakat → zakat; as-sadaqa → charity (sadaqa)
- as-sawm → fasting; al-hajj → the pilgrimage (hajj); adh-dhikr → remembrance (dhikr); al-wird / al-awrad → daily litany (wird); ad-du'a' → supplication
- qiyam al-layl → night prayer; at-tahajjud → tahajjud; al-i'tikaf → retreat in the mosque (i'tikaf)

## Heart and self
- al-qalb → the heart; an-nafs → the self (nafs), or the soul when context requires; ar-ruh → the spirit; al-hawa → caprice (hawa)
- ash-shahwa → appetite; al-ghadab → anger; al-khawatir → passing thoughts; al-waswasa → whispering
- ash-shaytan → Satan; Iblis → Iblis; al-mala'ika → the angels
- an-niyya → intention; al-ikhlas → sincerity; as-sidq → truthfulness

## Destructive traits (al-muhlikat)
- ar-riya' → showing off (riya'); al-'ujb → self-admiration ('ujb); al-kibr → arrogance; al-ghurur → self-delusion (ghurur)
- al-hasad → envy; al-hiqd → rancour; al-bukhl → miserliness; hubb ad-dunya → love of this world; hubb al-jah → love of status
- al-ghiba → backbiting; an-namima → talebearing; al-kadhib → lying; al-ghafla → heedlessness; tul al-amal → long hope

## Saving traits (al-munjiyat)
- at-tawba → repentance; as-sabr → patience; ash-shukr → gratitude; al-khawf → fear (of Allah); ar-raja' → hope (in Allah)
- al-faqr → poverty; az-zuhd → renunciation (zuhd); at-tawhid → affirmation of Divine oneness (tawhid); at-tawakkul → reliance on Allah (tawakkul)
- al-mahabba → love (of Allah); ash-shawq → longing; al-uns → intimacy (uns); ar-rida → contentment (rida)
- al-muraqaba → vigilance (muraqaba); al-muhasaba → self-examination (muhasaba); at-tafakkur → reflection
- dhikr al-mawt → remembrance of death; al-wara' → scrupulousness (wara'); at-taqwa → God-consciousness (taqwa)
- al-khushu' → humility in prayer (khushu'); at-tawadu' → humility; al-yaqin → certainty; al-qana'a → contentment with little (qana'a)

## Path and states
- at-tariq → the path (to Allah); al-maqam / al-maqamat → station(s) (maqam); al-hal / al-ahwal → state(s) (hal)
- al-ma'rifa → knowledge of Allah (ma'rifa); al-mukashafa → unveiling; al-mushahada → witnessing
- al-mujahada → spiritual struggle (mujahada); ar-riyada → spiritual discipline (riyada); al-akhlaq → character; al-adab → proper conduct (adab)

## The Hereafter
- ad-dunya → this world; al-akhira → the Hereafter; al-qabr → the grave; al-qiyama → the Resurrection; al-hisab → the reckoning
- al-janna → Paradise; an-nar / jahannam → the Fire / Hell; as-sirat → the Bridge (sirat); al-mizan → the Scale
- ath-thawab → reward; al-'iqab → punishment; ar-ru'ya → the vision of Allah (in the Hereafter)
