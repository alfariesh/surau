# Standar Jalur 7 hari (konten@1)

Sumber angka: `CONTENT_LIMITS` di `@surau/core`; [docs/09-konten.md](https://github.com/alfariesh/surau/blob/main/docs/09-konten.md) §5.4.

| Bagian | Standar |
|---|---|
| Judul | 3–12 kata, menyebut isi. Tanpa janji ("agar", "supaya", "raih", "kuasai") |
| Deskripsi | 15–60 kata |
| Hari | Tepat 7, bernomor 1–7, setiap hari satu bagian berbeda di dalam Kitab (`section_id` = ID Kitab) yang sudah punya Intisari tampil; urutan sebaiknya mengikuti kitab |
| Pengantar | 8–40 kata per hari, atributif, tanpa tugas atau target |
| Dari kode | menit baca, tombol "Baca teks lengkap", penafian "bukan pengganti guru", centang selesai di perangkat |
| Dilarang | sertifikat, ijazah, sanad, streak, lencana capaian, papan peringkat |
