# Standar Intisari Kitab (konten@1)

Sumber angka: `CONTENT_LIMITS` di `@surau/core`; [docs/09-konten.md](https://github.com/alfariesh/surau/blob/main/docs/09-konten.md) §5.2.

Kerangka tampil: **Inti → Pembuka → Ringkasan → 5–10 gagasan besar → Kutipan → Istilah → Penutup (+ "pintu ke teks" dari kode)**.

| Bagian | Standar |
|---|---|
| Inti | Satu kalimat, 12–35 kata, atributif |
| Pembuka | 40–120 kata: apa yang dibahas Kitab ini dan bagaimana urutannya. Tanpa janji manfaat |
| Ringkasan | 40–110 kata |
| Gagasan | 5–10. Judul 4–14 kata, tesis, menyebut pemilik pendapat, paling banyak sepertiga dibuka "Al-Ghazali". Isi 60–200 kata. `bab`: 1–10 ID bagian di dalam Kitab. `dasar`: 1–6 paragraf badan di dalam Kitab. Satu soal berjawaban per gagasan |
| Cakupan | Setiap Bab anak langsung dirujuk minimal satu gagasan (`uncovered_chapter` bila tidak) |
| Kutipan | 0–3, aturan sama dengan Intisari Bab |
| Istilah | 0–8 kunci glosarium |
| Penutup | 15–80 kata; ajakan kembali ke teks ditambahkan kode |

Gagasan Kitab tidak boleh sekadar mengulang gagasan Bab; ia menyatukan beberapa Bab menjadi satu alur (mis. "keutamaan ilmu", lalu "ilmu yang terpuji dan tercela", lalu "adab murid dan guru").
