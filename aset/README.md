# Aset visual Surau

Ilustrasi interaktif untuk landing page, blog, dan konten. Dibuat agent dengan skill `aset`
(`.claude/skills/aset/SKILL.md`); mesinnya turunan Colorfigures (MIT, April Zhu) yang dikunci ke gaya Surau.

- `figur/`: sumber tiap figur (HTML + satu skrip). Bisa dibuka langsung di browser selama dikerjakan.
- `keluaran/`: hasil siap pakai. `<nama>.html` berdiri sendiri (mesin sudah disisipkan), PNG dipotret dari file yang sama.

Coba: buka `keluaran/kitab-rehal.html` di browser, lalu tekan tombolnya atau ketuk kitabnya.
Tambahkan `?tema=gelap`, `?sematan=1`, atau `?sampul=1&judul=Judul%20artikel` di akhir alamat untuk melihat mode lain.
